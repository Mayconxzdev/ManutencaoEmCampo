# Política de segurança

Não publique vulnerabilidades, credenciais ou dados sensíveis em issues públicas.

Para reportar uma vulnerabilidade, abra uma discussão privada com o mantenedor do repositório pelo perfil [@Mayconxzdev](https://github.com/Mayconxzdev), descrevendo o impacto, o caminho de reprodução e uma sugestão de correção quando possível.

Esta demonstração não deve ser usada como implantação produtiva sem revisão de identidade, autorização, configuração de HTTPS, CORS, armazenamento, backup e observabilidade para o ambiente alvo.
