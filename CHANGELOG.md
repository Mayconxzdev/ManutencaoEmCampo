# Changelog

Todas as mudanças relevantes deste portfólio são registradas neste arquivo.

## 1.0.0-demo — 2026-07-23

- publicação da demonstração pública sanitizada de **Manutenção em Campo**;
- seed local inteiramente fictício com quatro ativos, quatro pessoas e checklists específicos por ativo;
- ciclo demonstrável de início, respostas, foto sintética, responsáveis distintos, PDF final com hash e dossiê local;
- interface responsiva para desktop, tablet e celular, com PWA de cache para consultas;
- testes de seed/segurança, testes de navegador, lint, build e CI no GitHub Actions;
- documentação de arquitetura, decisões, privacidade, segurança e contribuição.

## Convenção

`-demo` identifica uma versão de portfólio. Ela não representa certificação, homologação ou implantação em ambiente corporativo.
