# Privacidade e dados da demonstração

Este repositório foi preparado como portfólio público.

## O que existe

- código-fonte da aplicação;
- ativos, pessoas e OMs fictícios, gerados localmente por script;
- imagens de interface produzidas sobre a base demonstrativa;
- documentação técnica e instruções de execução.

## O que não existe

- banco de dados, arquivos, fotos, PDFs, checklists, nomes ou documentos de organizações reais;
- IPs internos, caminhos de rede, NAS, certificados, backups ou scripts de implantação corporativa;
- credenciais, tokens, chaves privadas ou arquivos `.env`;
- planilhas de origem ou histórico operacional.

## Regras para contribuições

Não envie dados reais para issues, pull requests, imagens, seeds ou testes. Use sempre informações sintéticas e revise `git status` antes de commitar. Arquivos em `data/`, `.e2e_data/`, bancos SQLite, evidências, relatórios e backups são ignorados por Git.
