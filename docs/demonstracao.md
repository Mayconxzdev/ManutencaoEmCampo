# Roteiro de demonstração

Use este roteiro para conhecer o projeto em menos de cinco minutos.

1. Execute a base fictícia com `python backend/scripts/seed_demo.py --reset`.
2. Abra a interface e selecione **Camila Duarte** ou **Rafael Moreira** para conferir uma execução.
3. Na página inicial, observe OMs para hoje, em atraso, em andamento e concluídas.
4. Abra **Iniciar Checklist Digital** e pesquise por `MEC-104`.
5. Selecione o ativo. O aplicativo mostra o registro anterior como contexto e permite iniciar uma nova execução sem apagar a anterior.
6. Responda os itens, adicione uma observação e avance até o resumo.
7. Selecione **Joana Lima** ou **Diego Farias** como responsável técnico e finalize.
8. Abra **Histórico** para consultar a nova trilha, responsáveis e artefatos gerados.

O cenário é deliberadamente fictício e pode ser recriado a qualquer momento. Nenhuma ação deste roteiro afeta recursos externos.
