# Contribuindo

Obrigado pelo interesse. Este é um projeto de portfólio funcional e aceita melhorias que preservem os princípios abaixo:

1. Não incluir dados reais, credenciais, imagens de clientes ou infraestrutura privada.
2. Manter a interface em português do Brasil e acessível para uso em campo.
3. Adicionar ou atualizar testes quando alterar regra de negócio.
4. Executar `pytest`, `npm run lint` e `npm run build` antes de abrir um pull request.
5. Explicar no pull request o problema, a decisão e o impacto no fluxo de manutenção.
